# v0.30 自助密码找回

OneStorage 在 Workers/D1 内提供一次性离线密码恢复密钥，不依赖邮件服务或容器。登录后打开“账户安全 → 忘记密码时恢复账户”，输入当前密码及已启用的第二因子生成密钥，立即下载或复制到安全位置。密钥只显示一次，有效期一年；同一账户仅保留一个，替换后旧密钥立即失效。

忘记密码时，从登录页进入“忘记密码？”，输入用户名、恢复密钥和新密码。启用了 MFA 的账户仍必须提供新的验证器代码或一个未用过的 **MFA 恢复码**。密码恢复密钥与 MFA 恢复码是两种不同凭据；单独持有其中一个不能绕过已启用的双重验证。

## 恢复结果与撤销

成功找回会在同一个 D1 事务中更新密码、消费恢复密钥、撤销所有浏览器会话和 PAT、删除 JWT 委托公钥及进行中的 OIDC 流程，并记录账户审计。不会自动登录；使用新密码和原有第二因子重新登录，再生成新的密码恢复密钥。

项目、空间、协作记录、角色、MFA 设置及剩余 MFA 恢复码保留；提交签名公钥和已关联的 OIDC 身份也保留。项目/空间部署令牌是独立主体，不随个人密码恢复删除。已经完成授权的在途业务操作不因本接口自动回滚；后续请求必须使用有效凭据。

修改密码（包括管理员重置）、启停 MFA、账户认证版本变更、停用账户以及管理员“撤销会话”都会使已保存的密码恢复密钥失效；重新启用账户不会复活旧密钥。账户安全页提供主动撤销及最近 20 次生成、撤销、使用记录，历史中不包含任何密钥、密码或验证码。

仅统一登录且尚未设置本地密码的账户不能创建该密钥，应通过已有 OIDC 登录，再在“修改密码”中设置本地密码。如未预先保存有效密钥，可使用已关联的统一登录或联系部署管理员核验身份。本版本没有邮件验证/邮件重置，也不允许此密钥关闭 MFA；丢失全部第二因子仍需要独立的身份核验恢复。这不是完整账户恢复体系已经完成的声明。

## 实现约束

- 32 字节密码学随机数，显示为 `osr_` 加分组十六进制。D1 只存绑定用户与版本的 SHA-256 摘要、时间及认证版本，不存可恢复明文。
- 生成和撤销要求浏览器会话、当前本地密码及启用时的新第二因子。提交 SQL 再检查会话仍存在、未过期、用户未停用、认证版本及 MFA 版本相同；调用方提供当前密钥版本，避免陈旧页面覆盖另一次轮换。
- 恢复查询、密码写入和凭据撤销再次检查当前认证版本、密钥版本/摘要/期限和 MFA 配置。条件更新只有一个并发请求可成功。审计写入失败会回滚密码和凭据变更。第二因子验证发生在密码事务之前，后续事务失败时已经使用的第二因子仍已消费；可以使用下一验证码或备用 MFA 恢复码再次操作。
- 不存在的用户、错误密钥、过期/已使用密钥和停用账户返回相同 401 消息，不对匿名请求暴露账户状态。恢复端点按 IP 和规范化用户名分别限制每十分钟 10 次；不能用 PAT、JWT 或部署令牌调用。
- 密钥只通过同源 JSON 请求体传入，绝不放进 URL、日志或浏览器持久存储。下载文件由浏览器本地生成；持有人须自行安全保存。响应使用 `no-store`。
- 如请求在数据库提交后网络中断，先使用新密码正常登录确认结果；不得假定错误响应意味着密码未更新。

## 接口与升级

`GET /api/account/password-recovery` 返回 `has_password,enabled,version,created_at,expires_at,history`；`PUT` 和 `DELETE` 同一路径接受 `{password,otp?,version}`，初次生成的 `version` 为 `null`。生成响应含 `{key,version,created_at,expires_at}`，禁止记录。

`POST /api/recover-password` 接受 `{username,key,new_password,otp?}`，成功返回 `{ok:true,sign_in_required:true}`。API 不要求登录；Cookie 写请求仍要求同源 Origin。

升级前备份 D1，应用 `0024_password_recovery.sql`，然后部署主 Worker。迁移仅添加恢复表和撤销触发器，不为现有用户自动启用恢复。应用网关和编译 Worker 无须变化。

设计参考：[OWASP 密码找回](https://cheatsheetseries.owasp.org/cheatsheets/Forgot_Password_Cheat_Sheet.html)与 [NIST 认证器生命周期](https://pages.nist.gov/800-63-4/sp800-63b/events/)。这些参考不表示本服务已取得相应等级的合规认证。
