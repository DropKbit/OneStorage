生产迁移前导出 D1，以关闭外键导入、重新启用外键的方式恢复到隔离 SQLite；原有 69 张表计数一致，迁移 0026 后完整性检查正常、外键错误为零。这只验证 D1 备份与迁移，不等同于完整 R2/DO 灾备演练。候选部署 `761394b9-cba5-4186-a4f7-ebf85acd2d23` 的生产验收通过 29 次 API 响应断言（包含轮询）：19 个文本文件、2 个明确跳过文件，原生 clone/push/rename/delete/fsck、维护者网页重建、固定提交行跳转、撤权、手机布局及默认分支切换均通过。首次索引 SHA 为 `5150a255de06dfa6aac9626e712050ec7fa3aa6d`，原生更新后为 `7418a9821a04130635e9517606b80e3adfee271a`，切换到 stable 后恢复为首次 SHA 的路径集合。桌面与手机截图均检查，浏览器异常为零。
