## 数据与边界

升级前导出生产 D1，在独立 SQLite 副本执行 `0018_oidc.sql`，完整性与外键检查通过，56 张既有表的行数保持不变；既有用户保留本地密码能力，既有凭据的 OIDC 来源字段为空。随后在生产成功应用迁移。备份仅覆盖 D1，不代表 R2/DO 全站恢复验收。

真实身份服务是独立、受随机密码保护的临时 Cloudflare Worker/DO，用 ES256 签名并验证 PKCE。客户端密钥、测试密码、签名私钥和生产 PAT 都通过本地私有文件管理，已检查公开源码归档不含这些值。验收程序结束时解除测试关联、删除提供方并停用临时账户；临时身份 Worker 在全部验收结束后删除。

本次不修改或重新部署应用网关和编译 Worker，不改变 Git 对象布局及服务域名。最终线上资产/源码校验使用 `npm run verify:release`，源码推送后从独立镜像 fetch 并进行严格 fsck，保留本地私有发布报告。

尚未配置或验证 Google/Microsoft 等商业身份提供方的真实账户；用户需提供自己的应用配置。普通 OAuth、Access JWT、SCIM、后台退出通知和完整 GitLab API/YAML 兼容仍不在本次完成声明内，总平台目标继续有效。
