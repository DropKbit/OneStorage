# v0.33 OAuth 验收记录

本阶段添加 GitHub 与 GitLab OAuth 登录适配，完整 GitLab/Gogs 平台目标继续有效。

类型检查及 349 项测试通过。新增检查覆盖固定 HTTPS endpoint/可信主机、PKCE 参数、稳定数字 ID、token/admin 字段不返回、GitHub 已验证邮箱与有界分页、GitLab 活跃账户和已确认主邮箱、畸形 token/响应/重定向/超限 JSON，以及账户关联后改名仍登录同一用户、提供方停用和登录中配置变更使流程失效。原有 OIDC 测试也通过。

本地 Cloudflare 浏览器验收通过 38 次响应及场景断言。验证管理员界面协议选择/配置、外部账户显式关联、稳定 ID 登录、本地 MFA（错误码拒绝与恢复码完成）、提供方停用后的会话/PAT 撤销、普通无密码注册、最后一种登录方式保护、设置本地密码及手机布局。D1 实际查询确认夹具身份、凭据、启用或仍为管理员的夹具账户、提供方与流程均为零；禁用账户和审计历史保留。

浏览器验收使用独立临时 Worker/DO 提供方。它实现 GitLab OAuth 协议，用随机独立凭据和一次性代码测试真实网络路径；不是对商业 GitHub/GitLab 应用的实测声明。最终本地/生产证据在验收后补记。
