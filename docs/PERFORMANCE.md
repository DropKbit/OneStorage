# 页面加载性能

**简体中文** · [English](en/PERFORMANCE.md)

## v0.39：根目录持久缓存与预热

根目录和 README 现在按 Git 目标对象 ID 保存在当前仓库的 Durable Object 中。普通/临时命名空间各一个固定槽，每槽最多 96 KiB，七天过期；不保存权限、分支列表或默认分支。每次请求仍经过当前权限、删除状态、项目版本和引用检查，引用变化立即重新读取。

推送/同步事件的后台维护会预热默认分支，减少用户第一次打开页面时的 R2 往返。DO 重建后仍可复用持久缓存。超过大小限制、缓存读写故障、过期、子目录/文件和复杂 revision 使用原有读取路径。没有预热的新提交首次访问仍需从 R2 读取；本次不改变大仓库及 Git 协议预算。删除仓库时清理缓存。

响应的 Server-Timing 提供 browse（缓存命中/未命中及耗时）、r2_reads（对象读取次数）、repo_queue 和 repo_total；不包含路径、凭据或用户内容。

验证：387 项测试通过；新增本地 test:browse-cache 验收后台预热、私有仓库拒绝匿名/无效凭据、写后立即可见。原生 Git/LFS/并发验收通过。停止并重新启动 workerd 后，已有根目录缓存命中，R2 读取为 0；单元测试冷对象存储对照为首次 3 次、持久命中 0 次。这些结果不代表全球 p95 或没有预热的新仓库性能。

以下为 v0.3.1 历史测量；其中 HTML 的 ETag 策略已在 v0.38 为语言协商调整。

2026-09-08，线上 `git.1s.hk`，私有仓库 `1shk/nb`。本次修复针对刷新时的整页“正在连接”和页面切换等待。

## 原因与改动

- 原页面等待身份初始化、仓库信息、分支、目录、README 全部完成后才绘制。现在 HTML 自带公共导航和加载占位，切换页面立即响应，身份和页面数据并行读取；离开页面取消旧的 GET，防止旧页面覆盖新页面。
- 原公共 HTML、JS、CSS 也查询身份数据库，且被统一设置为 `no-store`。现在公共资源在鉴权前处理，移除转发给资源服务的身份头；HTML 用 ETag 重新验证，带内容哈希的 JS/CSS 缓存一年，依赖模块预加载。API 和 Git 仍逐次鉴权。
- 新的 `GET /api/bootstrap` 合并身份与初始化检查；`GET /api/repos/:namespace/:repo/browse` 在同一 DO 请求返回分支、默认分支、目录或文件及同一提交的 README，替代三次串行请求。默认分支取自当次 DO 状态，编辑链接也使用该值。
- 所有者无需再查询成员表，仓库信息接口复用已求得的角色；DO 的只读请求不重复查询外层已检查的仓库元数据。
- 每个 DO 用最多 8 MiB / 512 项、单项最多 1 MiB、五分钟 TTL 的内存缓存复用已验证且已持久化的 Git 对象。缓存按仓库隔离、复制字节，写入失败与未发布对象不入缓存。引用和授权决定不缓存。浏览器仅在内存复用仓库描述等元数据 15 秒，写操作与权限错误清空，数据接口继续检查权限。

## 线上测量

使用 Node `fetch`，从请求开始到完整读取响应，带同一账号令牌，对同一个仓库测量。旧版本为 `d3a0104`，新版本首次部署为 `59277d89-4701-46f6-b325-5cf642b67b5b`。

| 指标                                         | 原版                   | 新版                                |
| -------------------------------------------- | ---------------------- | ----------------------------------- |
| 代码页仓库、分支、目录、README 串行总耗时    | 4,920 ms               | 改为并行仓库信息 + 聚合目录接口     |
| 部署后首次聚合目录接口                       | 无                     | 760 ms                              |
| 身份、仓库信息、聚合目录三个并行请求全部结束 | 无                     | 386 / 211 / 218 ms（三次连续采样）  |
| 公开 HTML 条件请求                           | 每次重新下载，no-store | 304，143 ms                         |
| 带版本 JS                                    | 无持久缓存             | public, max-age=31536000, immutable |

另一轮继续调用旧独立接口的对照中，仓库信息 / 分支 / 目录 / README 分别为 547 / 743 / 950 / 842 ms，说明时延仍随网络、连接和后端位置变化，不能把最好一轮当成稳定承诺。这些数据不包含完整浏览器渲染，不是 FCP、p95 或全球性能测试。DO 重启或对象缓存过期仍需要读取 R2。

## 验证

- TypeScript 与 60 项单元测试通过：包括公共资源绕过身份存储、私有 API/Git 继续鉴权、缓存隔离/复制/失败写入/容量/TTL。
- 本地 workerd：43 项基础 HTTP 检查和原生 Git/LFS/并发流程；76 项高级 HTTP 检查，包括空目录、聚合读取一致性、文件内容、默认分支、写后读取、缓存命中后的令牌撤销。签名 Git 推送与撤销检查通过。
- 浏览器实际切换代码、提交、Git 工具页面并检查内容。
- 线上聚合结果与原目录、README 接口逐项一致；匿名与无效令牌访问私有目录返回 401；API 保持 no-store；公共 HTML 条件请求返回 304，带版本脚本正确缓存。
- 生产构建通过，无数据库迁移、容器或新增收费服务。
