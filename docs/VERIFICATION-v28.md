## 自动检查

- `npm run check`：类型检查和 305 项单元测试通过，其中新增 8 项搜索测试。覆盖直接/继承权限、个人所有权、管理员不绕过私有项目、凭据到期/撤销/禁用、当前可见性/归档/转移/删除、字面中文和标点、正文片段、当前 Wiki、状态筛选及错误凭据类型。

## 本地真实运行时

`npm run test:search` 在本地 Wrangler Workers、D1、R2 和 Durable Objects 中完成，退出码 0。夹具含 3 个项目、3 条 Issue、1 条 MR 和 1 个 Wiki；通过提交文件/分支 API 创建实际 Git 对象及 MR。

51 次 API 响应检查（不含清理），含 22 次成功搜索。验证公开/私有隔离、直接与继承成员、只读 PAT、撤销、旧游标、状态/归档、中文和字面 `%_\\`、SQL 引号、长正文及 Wiki 修改即时生效。

Headless Chromium 完成 1440×1000 桌面和 390×844 手机页面、刷新、查询、结果跳转到具体 MR、浏览器返回、正文转义和命中高亮；无页面脚本异常或手机横向溢出。两张完整页面截图已目视检查。仅拥有项目权限时，空间选择器正确显示当前筛选空间。

最初浏览器验收因脚本未包含 MR 标题中的 `!编号` 而失败，已完成清理并修正选择器，随后完整重跑通过。
