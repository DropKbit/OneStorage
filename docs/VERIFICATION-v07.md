## 验证内容

本地和真实 Cloudflare 均使用独立测试空间、公开目标、普通用户的私有 Fork 及无权限观察者。验证来源候选过滤、不相关仓库拒绝、私有来源隐藏、贡献者不能直写或合并目标、作者不能自批、独立批准、源更新使旧批准失效、陈旧 PATCH 修订号拒绝、错误行号与路径拒绝、讨论回复/解决权限、过期讨论仍阻塞、访客讨论不能否决，以及维护者显式运行目标配置的固定源 SHA CI。

并发发送“合并”和“重开阻塞讨论”，断言不允许两者同时成功。若讨论先重开，重新解决后才能合并；若合并先完成，讨论变更返回冲突。合并重试返回同一持久化结果；已合并请求不能关闭或重新打开讨论。

在源 Fork 的另一条私有分支写入未发表文件。创建贡献后，直接读取目标仓库中的该提交返回缺失对象，原生 Git 克隆也不包含该提交。目标分支合并后拥有请求的固定提交历史，`git fsck --full --strict` 通过。源码请求创建时不写目标分支，不自动触发源仓库的流水线。

单元测试额外覆盖：Fork 网络中的兄弟与被删除祖先、私有/公开来源刷新权限、来源删除后目标快照保留、缺少来源对象时目标不发布、只复制可达 LFS 指针对应的内容、讨论/回复超过 100 条后的真实 HTTP 游标及私有访问拒绝、旧版本阻塞讨论的权限重新计算、行号映射中类似补丁头的源代码，以及文件名/代码 HTML 转义。

生产首轮新增“未发表提交不存在”断言预期为 404，而 Git 对象层约定返回 409；确认错误为 `Missing Git object` 后修正测试，完整重跑通过。失败轮及最终轮的测试仓库、空间均已清理，临时用户停用并撤销凭据。保留一个本地人工测试夹具供浏览器补验，不分发到源码包。

## 浏览器验收进展

v0.7 发布时桌面浏览器工具确认 Mac 已锁定，因此当时没有完成页面交互验收。2026-09-08 在 v0.13 工作树上使用独立 headless Chromium 完成专项补验：60 项接口/界面检查通过，另通过 API 创建 201 条分页夹具数据（不计作界面断言）。覆盖：

- 两个关联私有 Fork 的来源选择、分支加载期间禁止提交、切换后旧分支选项清除，以及通过真实表单创建跨 Fork 请求。
- 新/旧侧行定位、回复 Markdown、HTML 转义、解决和重新打开讨论；超过 100 条回复的追加加载、超过 100 条讨论的下一页导航。
- 作者/观察者无批准和合并入口、解决讨论门禁、要求修改和独立批准、固定版本 CI、移动端及最终合并。目标 main 确认等于返回的持久化 merged_sha。

同时修正通用表单绑定覆盖显式控件 ID 的问题：普通字段仍使用表单前缀避免重复，专门指定的来源仓库/分支 ID 保持稳定。通用浏览器回归 43 项通过，包含登录、管理员、空间/权限、代码高亮、Issue、CI、归档/恢复、重命名和移动端。

本地 MR 23 和新夹具 review_v07_be9f62a4 的 MR 53 已实际合并；分页测试创建的 MR 55 已关闭，其临时来源 Fork 已提交删除。复验先执行 `KEEP_REVIEW_FIXTURE=1 npm run test:reviews` 生成新的独立夹具，再按 CONTRIBUTING.md 配置 Playwright，执行 `npm run test:review-ui`。此脚本登录自己新建的隔离会话，结束后退出，不使用操作者的浏览器配置。保留主夹具用于检查结果，不包含在源码包中。

本次补验完成原记录列出的浏览器缺口；它不表示所有后续功能或完整 GitLab/Gogs 目标已经完成。
