# v0.35 npm 缓存验收

本阶段增加独立 R2 公共 npm 下载缓存，Cloudflare 原生 GitLab/Gogs 总目标继续有效。

类型检查及 358 项测试通过。新增检查覆盖跨编译实例命中、每次 SHA-512 验证、损坏缓存回退并修复、缓存读写故障、错误 registry 内容不写入、私有包跳过、命中仍计入压缩限额、取消缓存流、URL/SRI 键隔离、七天失效与不可用 R2 操作超时。既有锁文件、tar 路径/链接、完整性和私有包授权测试通过。

本地真实 Cloudflare 构建验收通过 25 项检查、43 次 API 请求。首次 Preact 10.29.3 构建下载 408,457 字节并写入缓存；新构建命中一次，未发生 registry 下载或缓存写入，两次产物均成功发布并可回滚。错误 SRI 和不支持的原生模块不产生可发布产物；浏览器 JS/CSS 静态应用可访问。实际 D1 查询确认测试空间、项目、流水线及应用版本均为零。

专用桶 `onestorage-npm-cache` 已创建，`npm-v1/` 七天过期规则及关闭 r2.dev 公共访问已通过 Wrangler 读取验证。编译 Worker 仅新增该桶绑定，主服务数据库 schema 保持 0027；Git 数据、应用网关配置与 Cubelink 不变。缓存条目是可丢弃派生数据，生命周期配置验证不代表已等待七天并观察到删除。

生产候选主 Worker `6872c843-a3f1-4f88-b892-f03e7704a9b0` 与编译 Worker `75f072a0-905e-4048-83ba-0531051f8427` 通过公共构建 25 项检查、47 次 API 请求，首次写入 408,457 字节缓存，第二次命中且下载量为零。另经 Wrangler 从生产 R2 直接读回压缩包，其大小和 SHA-512 与锁文件一致。19 个线上资源与本地发布包逐字节匹配，health 0.35.0、API/Git 鉴权以及 Cubelink 检查通过。公共测试项目清理后，实际 D1 查询确认空间、项目、流水线和发布版本均为零。

同一生产版本通过私有包回归 30 项检查、89 次 API 请求。混合构建包含两个完整性校验后的包，仅公共依赖计入一次缓存命中，下载量为零；私有依赖仍由控制面授权供给。未声明私有仓库、轮换后的旧令牌和最终撤销令牌均使构建失败且不生成产物，更新加密变量后构建恢复。应用发布、回滚和静态产物继续通过。私有夹具已完成异步清理；实际 D1 查询确认空间、两个项目、流水线、发布版本、CI 变量、包版本、部署令牌和私有包输入引用均为零。公共 npm 缓存按七天策略保留，用户原有账户和凭据保持有效。最终验收文档版本不改变已通过上述检查的运行时代码。
