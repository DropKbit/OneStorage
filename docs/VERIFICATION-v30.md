# v0.30 密码恢复验收

**简体中文** · [English](en/VERIFICATION-v30.md)

本阶段完成 Workers/D1 内的离线密钥密码找回及密钥写入撤权校验，保持无容器架构。使用流程、第二因子要求和剩余恢复能力见 [密码恢复说明](PASSWORD-RECOVERY-v30.md)。完整 GitLab/Gogs 目标继续推进。

## 测试与并发证据

类型检查及 320 项测试通过。新增 8 项测试覆盖密钥摘要与版本、轮换/撤销、到期与停用、管理员撤销、仅统一登录账户限制、跨域与 PAT 拒绝、一次性并发消费、旧会话/PAT/JWT 公钥撤销、OIDC 待办流程删除、签名公钥和关联身份保留、MFA 验证及防重放、审计失败事务回滚、相同匿名错误和速率限制。

额外故障注入复现了既有身份密钥接口的在途写入缺口：先完成会话读取，在实际公钥 INSERT 前撤销会话，原实现仍返回 201 并留下一个密钥。修复后同一注入返回 403，密钥数量为零。单元测试同时覆盖 JWT 委托公钥与真实 SSH Ed25519 签名公钥的创建/删除、会话删除/过期和用户停用；正常的密钥注册仍然成功。

这证明所测写入路径重新验证了当前会话，不代表所有已授权的在途业务操作都会因密码恢复自动回滚。

## 本地与 Cloudflare 浏览器验收

- 从登录页“忘记密码？”进入手机恢复页面，完成未启用 MFA 的密码找回；旧会话、PAT 和实际 JWT 均被拒绝，重新登录后 Git 文件字节不变。
