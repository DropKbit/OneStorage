- 本地 v2/v0 冷克隆约 2.88/2.81 秒；后续新提交 push 84 毫秒，两种协议增量 fetch 均约 103 毫秒。这些是本机 Workers/R2 模拟器结果，不能用作生产性能承诺。

- 本地项目转移回归 80 项、协作与隔离云 CI 82 项通过；计数包含状态轮询。认证头调整后，核心回归再通过 43 项 API 断言及原生 Git v0/v2、增量 thin push、并发引用更新、LFS、权限与 R2 持久化检查。

- 大仓库生产复验通过 47 项检查：5,424 个对象、42 MiB 随机内容，原生 v0/v2 clone、增量 push/fetch、`git fsck --full --strict`、匿名拒绝、中断下载后恢复访问。v2/v0 克隆耗时 640,543/366,723 毫秒，增量 push 4,192 毫秒，v2/v0 fetch 5,519/3,496 毫秒。生产私有仓库传输完整性通过，但冷克隆性能仍须优化。
